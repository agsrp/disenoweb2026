## 🚀 Despliegue en GitHub Pages

Este proyecto está 100% optimizado y listo para ser publicado en **GitHub Pages** de forma gratuita en 3 pasos:

### 1. Inicializar repositorio Git y subir los archivos
Abre una terminal en esta carpeta y ejecuta:
```bash
git init
git add .
git commit -m "feat: plataforma interactiva curso de diseno web 2026"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
git push -u origin main
```

### 2. Activar GitHub Pages
1. Entra a tu repositorio en GitHub.
2. Ve a la pestaña **Settings** (Configuración) → sección **Pages** (en el menú lateral izquierdo).
3. En **Build and deployment** / **Source**:
   - Selecciona **Deploy from a branch**.
   - Branch: selecciona **main** y carpeta `/ (root)`.
4. Haz clic en **Save**.

En 1 o 2 minutos, tu plataforma estará online en:  
`https://TU_USUARIO.github.io/TU_REPOSITORIO/`

## 📱 Características Responsivas y Técnicas
- **Mobile First & Responsive:** Menú hamburguesa (☰) interactivo con cierre táctil y tecla `Escape`.
- **Compatibilidad Celular Total:** Vistas optimizadas para pantallas desde 360px (móviles compactos y gama media) hasta monitores UltraWide.
- **21 Clases Modulares:** Navegación independiente tanto en portal único (`index.html`) como en páginas dedicadas (`clase_01.html` a `clase_21.html`).
- **Seguimiento Pedagógico en Vivo:** Sistema de asistencia y calificaciones integrado con Google Sheets mediante Webhook de Google Apps Script (`student_tracker.js`).
- **Laboratorios Interactivos:** Mezclador HSL/RGB en vivo, probador de contraste WCAG, simulador de inspector DevTools F12 y generador de User Persona.
