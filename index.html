PROGRAMA ACADÉMICO

Estructura Pedagógica de los 6 Módulos (Hacé clic para ver detalles)

MÓDULO 01 // CLASES 1 A 3
Entender la Web y el Problema

Cómo funciona la web, User Persona, Moodboard de color y tipografía, y Wireframes en papel antes de tocar código.

MÓDULO 02 // CLASES 4 A 7
Fundamentos de Código (HTML y CSS)

HTML5 semántico, estilos CSS, el Modelo de Caja, maquetación con Flexbox y diseño adaptable a celulares (Media Queries).

MÓDULO 03 // CLASES 8 A 10
Herramientas Profesionales e IA

Creación de assets en Canva, IA para textos y asistencia en código, CSS Grid, variables globales y organización con Trello.

MÓDULO 04 // CLASES 11 A 15
Proyecto Integrador en Aula

Producción intensiva de tu sitio web de 4 secciones, transiciones y animaciones CSS, y simulación + examen parcial práctico.

MÓDULO 05 // CLASES 16 A 18
Salida Laboral, SEO y Deploy

Cómo presupuestar y cobrar una web en Argentina, SEO On-Page y publicación gratuita en vivo con Vercel o Netlify.

MÓDULO 06 // CLASES 19 A 21
Optimización, QA y Defensa Final

Auditoría de velocidad con Lighthouse, clínica de código final, armado de CV profesional y presentación del sitio en vivo.

FILOSOFÍA DE ENSEÑANZA

Nuestros 4 Pilares de Aprendizaje Práctico

🧠

1. Primero Pienso, Después Codifico

Bocetamos la arquitectura de información, sitemaps y wireframes en papel y fibra antes de escribir una sola línea de código en el editor.

📱

2. Filosofía Mobile First Real

Diseñamos primero para pantallas de celular (360px) donde ocurre más del 80% del tráfico web real en Latinoamérica, y luego expandimos a escritorio.

🤖

3. IA como Copiloto en el IDE

Utilizamos herramientas de IA para autocompletar código y generar textos realistas de clientes, manteniendo siempre el criterio y comprensión técnica propia.

💼

4. Enfoque en Salida Laboral

Aprendemos a armar presupuestos en ARS, redactar contratos básicos contra 'scope creep' y publicar proyectos en la nube con enlaces públicos comprobables.
